# Security

Report security issues privately. Do not use a public GitLab issue. Either:

- open a **confidential** issue at
  <https://gitlab.com/bart-turczynski/seor/-/work_items> (tick "This issue is
  confidential" when you create it), or
- email the maintainer at <bartek@turczynski.pl>.

GitLab Free has no private vulnerability reporting like GitHub's, so a
confidential issue is the closest supported channel. The GitHub repository is a
read-only mirror and does not accept reports.

Do not include secrets, credentials, tokens, or private customer data in issues, merge requests, logs, or `_scratch/`.
